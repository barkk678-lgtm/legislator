# מנסח החקיקה

מערכת לניסוח הצעות חוק ישראליות בתבנית הרשמית של הכנסת.

## התחלה

```bash
pip install lxml
python3 tests/golden/test_kaytanot.py
```

צפוי: `תוצאה: עבר` — שמונה שורות, התאמה מלאה מול קובץ הצעת חוק אמיתי.

## מפה

| נתיב | תוכן |
|---|---|
| `CLAUDE.md` | חוקי הברזל של הפרויקט. לקרוא ראשון |

| `TASKS.md` | רשימת המשימות וסדר הביצוע |
| `docs/open-gaps.md` | מה לא עובד, מדורג לפי השפעה על המשתמש |

| `docs/data-sources.md` | מאיפה מביאים נוסחי חוקים |
