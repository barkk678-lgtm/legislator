# רשימת בדיקות הוולידטור

רצה על כל פלט לפני הצגה. כל כשל = אזהרה מוצגת למשתמש, לא כשל שקט.
מקור הכללים: `docs/drafting-rules.md` (משימה 1).

| # | בדיקה |
|---|---|
| 1 | מספרי הסעיפים בהוראות התיקון קיימים בפועל בחוק המתוקן |
| 2 | כל אזכור חוק חיצוני מלווה בהערת שוליים עם מראה מקום ברשומות |
| 3 | הסעיף הראשון מגדיר `(להלן – החוק העיקרי)` והשאר משתמשים בו |
| 4 | לכל סעיף יש כותרת שוליים, והיא מתארת את מהות התיקון |
| 5 | מרכאות: שימוש עקבי ב-`"` (U+0022), לא ב-`״` (U+05F4) |
| 6 | מקף בשנה עברית הוא en-dash (U+2013): `התשל"ז–1977` |
| 7 | שם ההצעה בפורמט `חוק X (תיקון – {תיאור}), התש{ע}–{ל}` |
| 8 | השנה בשם ההצעה היא שנת ההצעה, לא שנת החוק המקורי |
| 9 | סעיפים מסודרים כרונולוגית לפי סדרם בחוק המתוקן |
| 10 | תיקונים עקיפים באים אחרי התיקונים לחוק העיקרי |
| 11 | הגדרות בסדר אלפביתי, ללא הוראות אופרטיביות |
| 12 | סעיפי תחילה / תחולה / הוראת מעבר בסוף |
| 13 | נבדקו הצעות זהות או דומות, ונוספה השורה הנדרשת בדברי ההסבר |
| 14 | הסגנונות בקובץ ה-docx תואמים לתבנית (ראה `docs/template-spec.md`) |
| 15 | אין בפלט טקסט חוק שאין לו provenance |
