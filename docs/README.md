# אינדקס התיעוד — מי מקור האמת לכל נושא

> נכתב 2026-09-18. המטרה: שיחה חדשה תדע לאן ללכת בלי לקרוא הכול.
>
> **הכלל היחיד שחשוב כאן: לכל נושא יש מסמך אחד שהוא מקור האמת.**
> אם שני מסמכים סותרים — הטבלה למטה קובעת מי גובר. ואם מסמך סותר
> את **הקוד**, הקוד גובר תמיד; המסמך הוא הבאג.

## סדר קריאה לשיחה חדשה

1. **`CLAUDE.md`** — חוקי הברזל. בלי זה אסור לגעת בקוד.
2. **`PROJECT_CONTEXT.md`** — **חזון המוצר**: מה המערכת אמורה להיות, למי, והמודל העסקי. מתאר יעד, לא מצב.
3. **`docs/open-gaps.md`** — מה לא עובד, מדורג לפי השפעה.
4. **`TASKS.md`** — מה עשינו ובאיזה סדר (ארוך; לחיפוש, לא לקריאה רצופה).

## מסמכים שהם תמונת מצב ולא מקור אמת

`night-report.md`, `chat-tools-review-*.md`, `kns-unmatched-titles-*.md`,
`strategy/plan.md` ושני מסמכי התכנון שמומשו — **אלה מסמכים מתוארכים.**
הם נכונים ליום שנכתבו. אם הם סותרים את הקוד או את `open-gaps.md`, הם
המיושנים.

**ושלוש דרגות שונות, שלא לבלבל ביניהן:**

| מסמך | מה הוא |
|---|---|
| `PROJECT_CONTEXT.md` | **יעד** — מה המערכת אמורה להיות |
| `TASKS.md` + `open-gaps.md` | **מצב** — מה נבנה ומה לא עובד |
| `strategy/plan.md` | **היסטוריה** — מה תכננו בספטמבר |
