# מצב נוכחי מול התוכנית האסטרטגית

`docs/strategy/plan.md` הוא מסמך האסטרטגיה הקבוע (קריאה בלבד, לא
נערך כאן - ראו הכותרת שלו). המסמך הזה הוא רק "היכן אנחנו עומדים
עכשיו" ביחס אליו - מתעדכן בכל סבב עבודה.

## שלב נוכחי: שלב 0 (פריסה)

טרם התחיל בפועל. נדרש לפני זה: החלטות שדורשות את ברק (עלויות/
חשבונות - דומיין, הרשאות Vercel/Supabase) - ראו `decisions.md`.

## מה כבר קיים (מחוץ לסדר של plan.md, מלפני שהוא נכתב)

- לשונית "הצעות חוק": מנוע + API + ממשק עובדים על שני חוקי fixture,
  בלי דאטהבייס (state בלקוח בלבד). עיצוב לפי docs/design/ - הושלם.
  זה **לא** תואם עדיין את plan.md (שמצפה לקורפוס מלא מ-Supabase לפני
  שהכלי "נסגר" בשלב 3) - נשאר על fixtures עד שלב 1 יושלם.
- `docs/design/` (מוקאפ עיצובי + README) - תואם לשלב 0/כל השלבים,
  לא ספציפי לשלב אחד.

## תשתית קיימת רלוונטית לשלב 0-1

- שני פרויקטי Supabase בחשבון ("121", "ניהול מפעלים") - **אף אחד
